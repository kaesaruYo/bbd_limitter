# bbd_limitter（未完成）
賞味/消費期限を管理・リマインドする Android アプリ（Jetpack Compose）です。

## 実装済み機能
- JAN コード（手入力）または商品名手入力で商品登録
- JAN コード入力時は Open Food Facts API から商品名・画像URLを自動補完（取得できなければ手入力名で登録）
- 商品ごとの管理項目
  - 商品名
  - 商品画像URL（JAN 取得）
  - 個数
  - 保管場所
  - 賞味/消費期限
  - 期限通知（何日前に通知するか）
- 野菜・果物向けの「保存目安日数」入力（期限がない品目向け）
- 保管場所を自由追加
- 毎日 WorkManager で期限チェックし、通知
- JSON エクスポート/インポート（機種変更時のバックアップ用途）

## アカウント連携（Google / Apple）について
- **Google サインイン**は Android 単体でも実装可能です（Firebase Authentication を使う方法が一般的）。
- **Apple サインイン**は Android から実装する場合、通常は OAuth のリダイレクト先やトークン検証のためのバックエンドが必要になりやすく、Google よりハードルが高いです。
- 「サーバーを持たずに確実に運用したい」前提なら、まずは本実装のように **ローカル保存 + JSON エクスポート/インポート**が現実的です。
